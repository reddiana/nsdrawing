# 기술 노트

- 질문에 답하면서 설명한 기술은 주제마다 노트 하나로 남깁니다. (파일 이름: 영어 kebab-case, 예: `virtual-dom.md`)
- 노트에는 "한 줄 요약 → 백엔드로 비유하면 → NSDrawing에서 어디에 쓰나 → 더 읽을거리" 순서로 씁니다.
