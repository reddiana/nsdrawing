# Claude Code 초보자의 배움 기록

이 프로젝트는 **Claude Code를 처음 쓰는 사람**이 Claude와 함께 프로그램을 만들어 가는 과정이기도 합니다.
NS 차트 편집기를 만드는 이야기와 함께, "AI와 일하는 법을 배워 가는 이야기"를 여기에 모읍니다. 영상에서 별도 챕터로 쓸 수 있습니다.

## 2026-10-07 — 첫날 배운 것

### 대화로 일하는 법

| # | 배운 것 | 그 순간 |
| --- | --- | --- |
| 1 | **질문으로 시작해도 된다.** 웹 검색으로 자료를 찾아 준다. | "NS Chart를 설명한 사이트를 추천해주세요" |
| 2 | **"제안해 주세요"로 시작해서 대화로 다듬는다.** 처음부터 완벽한 지시를 할 필요가 없다. | 요구사항 초안을 받고, 하나씩 고쳐 나감 |
| 3 | **파일로 남겨 달라고 하면 내 컴퓨터에 파일을 만든다.** 그 파일을 내가 직접 편집할 수 있다. | "요구사항을 md로 저장해주세요. 내가 내용을 편집하겠습니다." |
| 4 | **내가 쓰는 도구를 알려 주면 거기에 맞춰 준다.** | "나는 md파일을 obsidian으로 읽고 편집합니다." → 태그·체크박스·콜아웃 형식으로 바뀜 |
| 5 | **결정하기 전에 비교를 부탁할 수 있다.** 장단점과 추천을 받고, 결정은 내가 한다. | JSON vs YAML 비교 → "JSON으로 결정하고 요구사항에 추가해주세요" |
| 6 | **"내 의도가 이해가나요?"라고 물어보면 좋다.** Claude가 이해한 내용을 그림과 함께 되돌려 주고, 내가 놓친 문제(트리 구조의 선택 규칙)까지 짚어 준다. | 감싸기 기능 제안 |
| 7 | **Claude가 질문하면 번호로 짧게 답해도 된다.** | "1번: 제안을 수용합니다. 2번: If/Case도 해주세요. 3번: 제안을 수용합니다." |
| 8 | **다른 프로그램의 동작을 예로 들면 잘 통한다.** | "drawio-obsidian plugin은 … 이 방식을 채택해주세요." |
| 9 | **Claude도 틀리거나 놓칠 수 있고, 내가 더 좋은 답을 낼 때도 있다.** | `.nsd` 확장자 충돌 → 내가 `.ns` / `.ns.svg`를 제안 |
| 10 | **문서 구조나 일하는 방식 자체도 같이 설계할 수 있다.** | 요구사항 / ADR / 설계 / 협업 기록 / 여정 기록으로 폴더를 나눔 |

### Claude Code의 동작 방식

| # | 배운 것 | 그 순간 |
| --- | --- | --- |
| 11 | **git 커밋도 부탁할 수 있다.** 커밋 메시지도 Claude가 쓴다. | "오늘은 여기까지 하겠습니다. git commit도 해주세요." |
| 12 | **Claude를 종료하면 대화 내용을 기억하지 못한다.** 자동 요약도 없다. | "클로드를 종료하고 다시 시작하면 recap 내용을 다시 알려주나요?" |
| 13 | **이전 대화를 이어서 열 수 있다.** `claude --continue`(마지막 대화), `claude --resume` 또는 `/resume`(목록에서 선택) | 위 질문의 답 |
| 14 | **`CLAUDE.md`는 Claude가 매번 자동으로 읽는 프로젝트 안내 파일이다.** 여기에 규칙을 적어 두면 새 세션에서도 지킨다. | "세션 시작 시 지난 작업 요약" 규칙을 넣음 |
| 15 | **기억은 파일로 남긴다.** 세션 기록(`collab/`)과 계획(`plan.md`)을 남겨 두면 새 세션에서도 이어갈 수 있다. | `collab/` 폴더를 만든 이유 |
