# 여정 기록

나중에 "사람과 AI가 함께 NS 차트 편집기를 만든 과정"을 YouTube 동영상으로 만들기 위한 재료를 모으는 곳입니다.

## `collab/`과의 차이

- `collab/`은 **일하기 위한** 기록입니다. 무엇을 결정했고 다음에 뭘 할지를 적습니다.
- `journey/`는 **이야기하기 위한** 기록입니다. 어떤 순간이 전환점이었는지, 무엇이 재미있었는지, 무엇을 보여 줄 수 있는지를 적습니다.

## 구성

| 위치 | 내용 |
| --- | --- |
| [[timeline]] | 날짜별 주요 사건과 전환점 |
| [[story-ideas]] | 영상 구성안, 챕터 아이디어, 장면 메모 |
| [[learning-claude-code]] | Claude Code 초보자가 배워 가는 과정 |
| `assets/` | 스크린샷, 화면 녹화, 그림 (파일 이름: `날짜-설명.png`) |

## 기록 원칙

- **전환점을 남긴다:** 방향이 바뀐 순간과 그 이유. (예: `.nsd` 충돌을 발견하고 `.ns`로 바꾼 일)
- **그때의 말을 남긴다:** 사용자의 요청 원문을 짧게 인용하면, 영상에서 그 순간을 생생하게 보여 줄 수 있습니다.
- **전후를 남긴다:** 문서나 화면이 어떻게 바뀌었는지 보여 줄 수 있도록 스크린샷이나 git 커밋을 연결합니다.
- **마일스톤마다 git 태그를 단다:** 나중에 그 시점의 저장소 상태를 다시 열어 볼 수 있습니다. (예: `journey/01-requirements`)
